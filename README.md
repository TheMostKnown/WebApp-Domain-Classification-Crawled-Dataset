# WebApp-Domain-Classification-Crawled-Dataset
Dataset for Web Applications' domain classification created utilizing crawling techniques

---
Набор данных для решения задач многоклассовой классификации домена веб-приложений на основе HTTP-трафика.
К публикации готовится статья, описывающая его создание и базовые показатели на основных моделях машинного и глубокого обучения.
После публикации здесь появится информация о том, как корректно процитировать данный датасет, если вы планируете его использовать в своей работе.
Корректное указание авторства является основным критерием возможности использования данного датасета в своих исследованиях.
